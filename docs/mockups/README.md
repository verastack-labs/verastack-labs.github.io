# Approved mockups

The prototypes each scene was agreed on in the 2026-09-28 brainstorm. They are HTML fragments
written for the brainstorm companion, which wraps them in its own frame, so open them for motion,
layout and copy, not as production code. Where a file shows several options, the spec says which
one was chosen.

| File | Scene | Chosen |
| --- | --- | --- |
| `brand-direction.html` | Brand and hero | B, Signal (dot matrix) |
| `scene-services-v2.html` | Services | pinned index with the configurator demo inside |
| `scene-work.html` | Work | A, cinema reel |
| `scene-products.html` | Products | A hand-over (desktop), C card swap (phones) |
| `scene-process-v2.html` | How we work | rail with split-flap indices, pinned |
| `scene-about-v5.html` | About | flicker boot-up, lines only after the boot |
| `scene-contact-v2.html` | Contact | the fill-in-the-blanks sentence (ignore hovers 1 and 3) |
| `contact-cta-words.html` | Book-a-call hover | 1, "bring · your · idea" |
| `nav.html` | Nav | the path pill that opens into a dock on hover, a vertical panel on touch |
| `footer.html` | Footer | the giant wordmark, bottom 40% cut off |

The configurator in `scene-services-v2.html` is an e-bike line drawing; the build uses a keyboard
model instead (spec 6.02).
